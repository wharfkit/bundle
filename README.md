# @wharfkit/bundle

A prepackaged bundle of common Wharf libraries re-exported for IIFE or ESM.

See the `package.json` or `src/main.ts` for a list of exported packages.

For usage examples, see either:

- `public/bundle.html` for IIFE (commonjs)
- `public/esm.html` for ESM (es module)
